# kriti

kriti sets a new efficiency frontier for open nepali asr: 119,462,146 live parameters, joint rank 1 on our 19-model development benchmark, and the lowest raw wer in the evaluated field.
architecture: `16 khz audio -> 80-bin log-mel -> conformer -> {nepali rnnt -> transcript; pooled encoder states -> 1,025-parameter danda head} -> text`
benchmark: kriti records 24.0773% punctuation-insensitive wer and the best raw wer, 24.6854%, among 19 fully evaluated systems on the frozen 3,630-utterance development view; it is joint first and leads the fine-tuned qwen3 nepali asr model, whisper large v3, and mms 1b variants while being far smaller.
